No clean Sunnify equivalent exists for a-Shell.

yt-dlp + spotDL is the only path that sometimes works. Both still depend on a functioning yt-dlp and the native ffmpeg. Spotify links themselves are not supported by yt-dlp.

Install and test:
python3 -m pip install -U yt-dlp
yt-dlp -x --audio-format mp3 "https://www.youtube.com/watch?v=dQw4w9wgXcQ"

If that fails, the exact error is required. spotDL is next:
python3 -m pip install spotdl
spotdl "https://open.spotify.com/track/..."

Expect dependency or memory failures. Desktop tools will not run. Pure-Python scrapers without yt-dlp are worse.

If you only need single tracks, pull title/artist from the public embed and feed the search string to yt-dlp. That is currently the least fragile route inside a-Shell.
